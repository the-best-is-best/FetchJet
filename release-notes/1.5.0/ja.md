## 1.5.0 の新機能

**アーカイブ**
- **ダウンロード後に展開：** ZIP、TAR、GZ、XZ ファイルは、完了時に自動で展開するか、行の新しい「展開」ボタンで展開できます。デスクトップでは、7-Zip がインストールされていれば 7Z、RAR、分割アーカイブ（.001、.part1.rar、.z01）、パスワード付きアーカイブも使えます。FetchJet がパスワードを尋ねます。
- **ファイルの展開先：** アーカイブ名のフォルダー、常にフォルダー、またはアーカイブの隣。展開後にアーカイブをごみ箱に移すこともできます。

**ダウンロード**
- **ダウンロードの右クリックメニュー**（スマートフォンでは長押し）：開く、フォルダーを開く、リンクをコピー、一時停止、再開、削除など。
- **サイトごとのフォルダー：** 選んだサイトからのダウンロードをすべて専用のフォルダーに保存します。
- **削除したファイルはごみ箱へ**（macOS と Linux ではゴミ箱）。すぐに消えることはありません。設定でオフにできます。
- **ダウンロード後にスキャン：** Windows では完了したファイルをお使いのウイルス対策ソフトで検査し、ウイルス対策ソフトがブロックしたダウンロードは分かりやすいメッセージとともにすぐに止まります。macOS では、ダウンロードしたファイルや展開したファイルに通常の「インターネットからダウンロード」の印が付きます。
- **月間レポート：** 設定 > ダウンロード に、月ごとのダウンロードしたファイル数、合計サイズ、ダウンロード元のサイトが表示されます。集計はお使いのデバイス内だけで行われます。

**ネットワーク（デスクトップ）**
- **独自の DNS：** FetchJet のダウンロードに使う DNS サーバー（DNS over HTTPS または通常の DNS サーバー）と、使用するネットワークアダプターを選べます。影響するのは FetchJet のダウンロードだけで、パソコンのほかの部分には影響しません。

**Windows**
- **新しいインストーラー：** Setup.exe と新しい MSI で、デスクトップとスタートメニューのショートカットを選べます。このバージョン、より新しいバージョン、より古いバージョンがすでにインストールされているかを知らせ、最後に FetchJet を起動できます。
- **ポータブル版：** インストールせずに動く .zip で、データは隣のフォルダーに保存されます。
- **新しい ffmpeg**（Windows と Linux、動画と音声を結合するツール）。次に FetchJet を起動したときに自動で更新されます。

**Android**
- **アプリが小さく：** ほとんどのスマートフォンで 83 MB から約 53 MB になり、インストール後の容量も少なくなりました。

**iPhone と iPad**
- **ログインが必要なページ（Zoom の録画など）：** FetchJet の中でページを開き、パスコードを一度入力すれば、そのページのセッションでダウンロードできます。Safari のページボタンにも「このページを FetchJet で開く」が加わりました。

**上級ユーザー向け**
- **コマンドライン：** `FetchJet status`、`pause`、`start`、`remove`、`delete` で実行中の FetchJet を操作できます。`FetchJet automation on` を実行するまではオフです。

**ブラウザー拡張機能 (3.5)**
- 指定したファイルの種類に限定しない限り、ブラウザーのすべてのダウンロードを引き受けます。
- Zoom の音声のみの録画にダウンロードボタン。
- フレーム内のプレーヤーが動画をより確実に見つけます。

**プライバシー**
- 利用者数を把握するため、FetchJet は 1 日 1 回匿名のメッセージを送るようになりました。内容はこのインストール用のランダムな番号、アプリのバージョン、システムで、国はサーバーが接続から読み取ります。リンク、ファイル、個人データは含みません。集計は README からリンクされた公開ページで見られます。
