## 1.5.0 新功能

**压缩包**
- **下载后解压：** ZIP、TAR、GZ 和 XZ 文件可以在下载完成时自动解压，也可以用行上新增的“解压”按钮解压。在桌面版上，只要安装了 7-Zip，7Z、RAR、分卷压缩包（.001、.part1.rar、.z01）和带密码的压缩包也都可以解压；FetchJet 会询问密码。
- **文件放在哪里：** 以压缩包命名的文件夹、始终放进一个文件夹，或者放在压缩包旁边。解压后还可以把压缩包移到回收站。

**下载**
- **下载项的右键菜单**（手机上为长按）：打开、打开所在文件夹、复制链接、暂停、继续、删除等。
- **按网站分文件夹：** 把来自你所选网站的所有内容放进它自己的文件夹。
- **删除的文件会进入回收站**（macOS 上为废纸篓，Linux 上为回收站），而不是直接消失。可以在设置中关闭。
- **下载后扫描：** Windows 会用你的杀毒软件检查下载完成的文件，被杀毒软件拦截的下载会立即停止，并给出清晰的提示。在 macOS 上，下载和解压出的文件会带有常见的“从互联网下载”标记。
- **月度报告：** 设置 > 下载 会按月显示你下载了多少个文件、总大小以及它们来自哪些网站。只在你的设备上统计。

**网络（桌面版）**
- **自定义 DNS：** 为 FetchJet 的下载选择一个 DNS 服务器（DNS over HTTPS 或普通 DNS 服务器），并选择它们使用哪个网络适配器。只影响 FetchJet 的下载，不影响电脑的其他部分。

**Windows**
- **新的安装程序：** 一个 Setup.exe 和一个新的 MSI，可以自行选择是否创建桌面和开始菜单快捷方式。它们会告诉你是否已经安装了此版本、更新或更旧的版本，并可以在安装结束时启动 FetchJet。
- **便携版：** 一个无需安装即可运行的 .zip，数据保存在它旁边的文件夹中。
- **更新的 ffmpeg**（Windows 和 Linux，用于合并视频和音频的工具）。下次启动 FetchJet 时会自动更新。

**Android**
- **应用更小：** 在大多数手机上约 53 MB，而不是 83 MB，安装后占用的空间也更少。

**iPhone 和 iPad**
- **需要登录的页面，例如 Zoom 录像：** 在 FetchJet 内打开页面，输入一次密码，然后使用该页面的会话下载。Safari 中的页面按钮也新增了“在 FetchJet 中打开此页面”。

**高级用户**
- **命令行：** `FetchJet status`、`pause`、`start`、`remove` 和 `delete` 可以控制正在运行的 FetchJet。在你运行 `FetchJet automation on` 之前它们处于关闭状态。

**浏览器扩展 (3.5)**
- 接管浏览器的所有下载，除非你将其限制为你列出的文件类型。
- Zoom 纯音频录像上新增下载按钮。
- 框架内的播放器能更可靠地找到它们的视频。

**隐私**
- FetchJet 现在每天发送一条匿名消息，让我们知道有多少人在使用它：本次安装的随机编号、应用版本和系统；服务器从连接中读取国家。不包含链接、文件或个人数据。汇总数据在 README 链接的公开页面上。
