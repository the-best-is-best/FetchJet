## 1.5.0의 새로운 기능

**압축 파일**
- **다운로드 후 압축 풀기:** ZIP, TAR, GZ, XZ 파일은 다운로드가 끝나면 저절로, 또는 행에 새로 생긴 압축 풀기 버튼으로 풀 수 있습니다. 데스크톱에서는 7-Zip이 설치되어 있으면 7Z, RAR, 분할 압축 파일(.001, .part1.rar, .z01), 암호가 걸린 압축 파일도 됩니다. FetchJet이 암호를 묻습니다.
- **파일이 풀리는 위치:** 압축 파일 이름의 폴더, 항상 폴더, 또는 압축 파일 옆. 압축을 푼 뒤 압축 파일을 휴지통으로 옮길 수도 있습니다.

**다운로드**
- **다운로드의 오른쪽 클릭 메뉴**(휴대폰에서는 길게 누르기): 열기, 폴더 열기, 링크 복사, 일시 중지, 재개, 삭제 등.
- **사이트별 폴더:** 사이트나 같은 방식으로 시작하는 링크(강좌, 프로젝트)에서 받는 모든 것을 선택한 폴더로 보냅니다. 브라우저에서 보낸 강좌도 따릅니다.
- **삭제한 파일은 휴지통으로 이동합니다**(macOS와 Linux에서도 휴지통). 바로 사라지지 않습니다. 설정에서 끌 수 있습니다.
- **다운로드 후 검사:** Windows는 완료된 파일을 사용 중인 백신으로 검사하고, 백신이 차단한 다운로드는 분명한 메시지와 함께 바로 멈춥니다. macOS에서는 다운로드하거나 압축을 푼 파일에 익숙한 "인터넷에서 다운로드됨" 표시가 붙습니다.

**네트워크(데스크톱)**
- **나만의 DNS:** FetchJet의 다운로드에 쓸 DNS 서버(DNS over HTTPS 또는 일반 DNS 서버)를 고르고, 사용할 네트워크 어댑터를 선택할 수 있습니다. 컴퓨터의 다른 부분이 아니라 FetchJet의 다운로드에만 적용됩니다.

**Windows**
- **새 설치 프로그램:** Setup.exe와 새 MSI에서 바탕 화면과 시작 메뉴 바로 가기를 직접 고를 수 있습니다. 이 버전이나 더 새로운 버전, 더 오래된 버전이 이미 설치되어 있으면 알려 주고, 마지막에 FetchJet을 실행할 수 있습니다.
- **포터블 버전:** 설치 없이 실행되는 .zip으로, 데이터는 바로 옆 폴더에 저장됩니다.
- **더 새로운 ffmpeg**(Windows와 Linux, 동영상과 오디오를 합치는 도구). 다음에 FetchJet을 시작할 때 저절로 업데이트됩니다.

**Android**
- **더 작아진 앱:** 대부분의 휴대폰에서 83 MB가 아니라 약 53 MB이며, 설치 후에도 공간을 덜 차지합니다.

**iPhone 및 iPad**
- **로그인이 필요한 페이지(예: Zoom 녹화):** FetchJet 안에서 페이지를 열고 암호를 한 번 입력한 뒤, 그 페이지의 세션으로 다운로드합니다. Safari의 페이지 버튼에도 "이 페이지를 FetchJet에서 열기"가 생겼습니다.

**고급 사용자용**
- **명령줄:** `FetchJet status`, `pause`, `start`, `remove`, `delete`로 실행 중인 FetchJet을 제어합니다. `FetchJet automation on`을 실행하기 전까지는 꺼져 있습니다.

**브라우저 확장 프로그램 (3.5)**
- 목록에 적은 파일 형식으로 제한하지 않는 한, 브라우저의 모든 다운로드를 가져옵니다.
- Zoom의 오디오 전용 녹화에 다운로드 버튼.
- 프레임 안의 플레이어가 동영상을 더 안정적으로 찾습니다.

**개인정보**
- 이제 FetchJet은 사용자 수를 알기 위해 하루에 한 번 익명 메시지를 보냅니다. 이 설치의 무작위 번호, 앱 버전, 시스템이 담기며, 서버는 연결에서 국가를 읽습니다. 링크, 파일, 개인 데이터는 없습니다. 합계는 README에 링크된 공개 페이지에 있습니다.
