## 1.4.0 の新機能

- **macOS：新しくなった、ずっと軽いアプリ。**Mac 版 FetchJet は Java なしで作り直されました。ウインドウを開いているときのメモリ使用量は約 60 MB、メニューバーでは約 35 MB で、以前の約 240 MB から大きく減りました。古いバージョンの上にそのままインストールでき、ダウンロード一覧、設定、保存したログイン情報、メディアツール、ブラウザ拡張機能、ペアリング済みのデバイスは引き継がれます。
- **iPhone：より軽く、より速く起動。**アプリのメモリ使用量が約半分になりました。動画エンジンは、動画の画質を初めて読み込むときに起動するため、その最初の読み込みだけ 1～2 秒長くかかります。
- **デバイスに送信：**ほかのデバイスから受け取ったファイルが、同じ名前のファイルを置き換えなくなりました。「名前 (1)」として保存されます。デバイスを探しているときに iPhone でまれに起きていたクラッシュを修正しました。
- **トレント：**「ダウンロードを追加」の名前欄に、トレント本来の名前が表示されるようになりました。

## お知らせ（macOS）

- 見た目は新しくなりましたが、ページとオプションは同じです。
- ウインドウを 680 x 480 より小さくすることはできなくなりました。
- 以前のバージョンと同様に、macOS が FetchJet の起動の許可をもう一度求める場合があります（システム設定 > プライバシーとセキュリティの「このまま開く」）。
