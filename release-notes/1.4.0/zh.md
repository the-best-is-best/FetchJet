## 1.4.0 新功能

- **macOS：全新的、轻量得多的应用。**Mac 版 FetchJet 已不依赖 Java 重新构建。窗口打开时约占用 60 MB 内存，在菜单栏中约 35 MB，而以前约为 240 MB。它可直接安装在旧版本之上：下载列表、设置、已保存的登录信息、媒体工具、浏览器扩展和已配对的设备都会保留。
- **iPhone：更轻、打开更快。**应用占用的内存约为原来的一半。视频引擎现在在你第一次读取视频画质时才启动，因此第一次读取会多花一两秒。
- **发送到设备：**从其他设备收到的文件不再覆盖同名文件，而是保存为“名称 (1)”。修复了在 iPhone 上查找设备时偶尔出现的崩溃。
- **种子：**“添加下载”中的名称框现在显示种子的真实名称。

## 须知（macOS）

- 外观是全新的，页面和选项保持不变。
- 窗口不能再缩小到 680 x 480 以下。
- 与之前的版本一样，macOS 可能会再次询问是否允许打开 FetchJet（在系统设置 > 隐私与安全性中点按“仍要打开”）。
