## Yang baru di 1.4.0

- **macOS: aplikasi baru yang jauh lebih ringan.** FetchJet untuk Mac dibangun ulang tanpa Java. Aplikasi ini memakai sekitar 60 MB memori saat jendela terbuka dan sekitar 35 MB di bilah menu, dibanding sekitar 240 MB sebelumnya. Aplikasi dipasang di atas versi lama: daftar unduhan, pengaturan, login tersimpan, alat media, ekstensi browser, dan perangkat yang dipasangkan tetap ada.
- **iPhone: lebih ringan dan lebih cepat dibuka.** Aplikasi memakai sekitar setengah memori dari sebelumnya. Mesin video kini mulai saat pertama kali Anda membaca kualitas video, jadi pembacaan pertama itu butuh satu atau dua detik lebih lama.
- **iPad:** aplikasi iPhone kini berjalan di iPad sebagai aplikasi iPad layar penuh.
- **Kompres audio (baru):** file audio yang sudah selesai mendapat tombol kompres: di barisnya pada komputer dan tablet, di detailnya pada ponsel. Pilih tingkat dan lihat ukuran barunya sebelum mulai. Pertahankan format file itu atau pilih M4A, MP3, atau Opus. File asli tetap disimpan.
- **Kirim ke perangkat:** file yang diterima dari perangkat lain tidak lagi menimpa file dengan nama yang sama; file disimpan sebagai "nama (1)". Memperbaiki crash langka di iPhone saat mencari perangkat.
- **Torrent:** kolom nama di Tambah unduhan kini menampilkan nama asli torrent.
- **Ekstensi browser:** tombol gunting pada video kini menjadi "Buka di FetchJet". Tombol ini membuka jendela Tambah unduhan, sehingga Anda memilih semuanya sebelum unduhan dimulai.

## Perlu diketahui (macOS)

- Tampilannya baru; halaman dan opsinya sama.
- Jendela tidak bisa lagi dikecilkan di bawah 680 x 480.
- macOS mungkin meminta izin sekali lagi untuk membuka FetchJet ("Tetap Buka" di Pengaturan Sistem > Privasi & Keamanan), seperti pada versi sebelumnya.
