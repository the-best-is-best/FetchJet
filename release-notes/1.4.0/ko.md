## 1.4.0의 새로운 기능

- **macOS: 새롭고 훨씬 가벼워진 앱.** Mac용 FetchJet을 Java 없이 새로 만들었습니다. 창을 열었을 때 메모리를 약 60 MB, 메뉴 막대에서는 약 35 MB 사용하며, 이전의 약 240 MB보다 크게 줄었습니다. 이전 버전 위에 그대로 설치되며 다운로드 목록, 설정, 저장된 로그인, 미디어 도구, 브라우저 확장 프로그램, 페어링된 기기가 유지됩니다.
- **iPhone: 더 가볍고 더 빨리 열립니다.** 앱이 이전의 절반 정도 메모리를 사용합니다. 비디오 엔진은 이제 비디오 화질을 처음 읽을 때 시작되므로, 그 첫 번째 읽기는 1~2초 더 걸립니다.
- **기기로 보내기:** 다른 기기에서 받은 파일이 같은 이름의 파일을 더 이상 덮어쓰지 않고 "이름 (1)"로 저장됩니다. 기기를 찾는 동안 iPhone에서 드물게 발생하던 충돌을 고쳤습니다.
- **토렌트:** 다운로드 추가의 이름 입력란에 이제 토렌트의 실제 이름이 표시됩니다.

## 알아 두세요 (macOS)

- 디자인은 새로워졌지만 페이지와 옵션은 그대로입니다.
- 창을 680 x 480보다 작게 만들 수 없습니다.
- 이전 버전과 마찬가지로 macOS가 FetchJet 열기를 허용할지 한 번 더 물을 수 있습니다(시스템 설정 > 개인정보 보호 및 보안의 "무조건 열기").
