## What's new in 1.4.0

- **macOS: a new, much lighter app.** FetchJet for Mac is rebuilt without Java. It uses about 60 MB of memory with the window open and about 35 MB in the menu bar, instead of about 240 MB. It installs over the old version: your downloads list, settings, saved logins, media tools, browser extension and paired devices are kept.
- **iPhone: lighter and faster to open.** The app uses about half the memory it did. The video engine now starts the first time you read a video's qualities, so that first read takes a second or two longer.
- **iPad:** the iPhone app now runs on iPad as a full-screen iPad app.
- **Compress audio (new):** a finished audio file gets a Compress button: on its row on computers and tablets, in its details on phones. Choose a level and see the new size before you start. Keep the file's own format or pick M4A, MP3 or Opus. The original file is kept.
- **Send to device:** a file received from another device no longer replaces a file with the same name; it is saved as "name (1)". Fixed a rare crash on iPhone while looking for devices.
- **Torrents:** the name box in Add download now shows the torrent's real name.
- **Browser extension:** the scissors button on a video is now "Open in FetchJet". It opens the Add download window, so you choose everything before the download starts.

## Good to know (macOS)

- The look is new; the pages and options are the same.
- The window can no longer be made smaller than 680 x 480.
- macOS may ask once more to allow FetchJet to open ("Open Anyway" in System Settings > Privacy & Security), as with earlier versions.
