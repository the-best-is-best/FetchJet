## 2.1.1의 새로운 기능

**미디어 플레이어**
- **새 기능:** 다운로드가 끝난 오디오와 동영상을 모든 플랫폼에서 FetchJet 안에서 재생합니다. 행의 재생 버튼, 폴더·재생목록·그룹 전체를 위한 「재생」, 이전 / 다음과 목록이 있는 재생 대기열, 재생 속도, 길게 눌러 2x 재생을 지원합니다. 마지막 재생 위치는 저장됩니다.
- **간결한 컨트롤:** 컨트롤은 동영상 위에 겹쳐 표시되고 3초 뒤에 사라집니다. 얇은 탐색 막대 하나와, 속도·**자동 재생** 스위치·**CC**가 있는 작은 줄 하나뿐입니다. 동영상이 일시중지되었거나 자동 재생이 꺼진 상태에서 다음 항목이 기다리고 있으면 가운데에 큰 ▶ 하나가 나타납니다.
- **자동 재생:** 켜면 다음 항목이 저절로 시작되고, 끄면 일시중지된 상태로 불러옵니다.
- **자막:** CC 메뉴에는 동영상에 들어 있는 자막, 동영상 옆에 있는 자막 파일(사용자 언어가 먼저), 「자막 파일 열기…」(SRT, VTT, ASS)가 표시됩니다. 선택은 다운로드마다 저장됩니다. 자막은 아래쪽에 표시되고, 컨트롤이 보일 때는 그 위로 올라갑니다. 자막이 켜져 있는 동안 CC가 채워져 표시됩니다.
- **휴대폰과 태블릿:** 오른쪽 절반을 위아래로 밀면 음량, 왼쪽 절반을 밀면 밝기가 바뀝니다(플레이어 안에서만).
- **컴퓨터:** 음소거 버튼이 있는 최대 200% 음량 슬라이더와 전체 화면. Windows, macOS, Linux에서는 플레이어 라이브러리를 처음 재생할 때만 진행 상황을 보여 주며 내려받고, 준비가 끝나면 파일이 저절로 열립니다.

**자르기, 추출, 압축**
- **동영상 자르기:** 행 메뉴나 세부 정보에서 시간으로 자르거나 타임라인에서 자릅니다. 타임라인은 동영상 편집기처럼 동작합니다. 고정된 시간 눈금, 드래그나 스크롤로 이동, 몇 초에서 동영상 전체까지 확대·축소, 가장자리에서 화면을 스크롤하는 핸들, 미리보기 이미지, 얇은 스크롤 막대가 있습니다. 클립은 새 파일로 원래 동영상 아래에 표시됩니다.
- **오디오 자르기:** 오디오 파일도 같은 방식으로, 음파 타임라인에서 자를 수 있습니다. MP3 부분은 원본과 같은 비트레이트로 다시 인코딩되므로 소리가 손실되지 않고 파일도 커지지 않습니다.
- **오디오 추출:** 동영상의 소리 트랙을 다시 인코딩하지 않고 별도 파일로 저장합니다.
- **원본 삭제:** 어떤 파일에서 아직 아무것도 만들지 않았다면, 자르기와 압축에서 「원본 삭제」를 고를 수 있습니다. 그러면 새 파일이 기본 다운로드가 됩니다. 자막을 추가하거나(자막 타이밍은 클립에 맞춰집니다) 다시 자르거나 압축할 수 있습니다. 다운로드를 삭제하면 그 다운로드에서 만든 클립과 사본도 함께 삭제되며, 확인 창에 그 개수가 표시됩니다.

**PDF 리더**
- **새 기능:** PDF 파일을 FetchJet 안에서 엽니다. 페이지가 위아래로 이어지고, 페이지 번호와 「페이지로 이동」, 너비 맞춤, 확대·축소를 지원하며, 마지막으로 읽은 페이지는 저장됩니다. Android와 iOS는 시스템 PDF 엔진을 쓰고, Windows, macOS, Linux는 처음에 작은 PDF 라이브러리를 내려받습니다. 설정에서 앱 안의 리더, 시스템 앱, 매번 묻기 중 하나를 고를 수 있습니다.

**숨긴 다운로드**
- **새 기능:** 다운로드, 재생목록, 폴더 그룹을 4~6자리 PIN이나 패턴 뒤에 숨길 수 있습니다(더보기 > 숨김). 숨긴 항목은 목록, 갤러리, 파일 관리자에서 사라지고 파일은 앱의 비공개 폴더로 옮겨집니다. 숨기기는 즉시 끝나며, 파일을 옮기는 동안 진행 상황이 한 줄로 표시됩니다. 숨김을 해제하면 파일이 원래 폴더로 돌아갑니다.
- **오디오와 영상은 암호화됩니다:** 숨긴 오디오와 영상은 기기에 묶인 키로 암호화되고 파일 이름은 뒤섞이며, 앱의 플레이어에서 재생하는 동안에만 복호화됩니다. 다른 형식의 파일은 눈에 띄지 않는 곳으로 옮겨질 뿐입니다. 처음 숨길 때 안내 메시지가 이를 설명합니다.
- **앱을 나가면 화면이 가려집니다:** 돌아오면 지문, Face ID, Windows Hello 또는 PIN을 요청하고, 재생 중이던 숨긴 동영상은 닫힙니다.
- **새 다운로드는 숨긴 상태로 시작합니다:** 숨김 화면(+ 버튼)에서 시작한 경우입니다. 숨긴 다운로드는 알림을 표시하지 않습니다.
- **PIN을 잊었을 때:** 휴대폰이나 컴퓨터의 잠금으로 확인한 뒤 새 PIN을 설정합니다. 숨긴 파일은 그대로 남습니다. Linux에서는 사용할 수 없습니다.
- **복구 코드:** 보관함 전체에 코드 하나이며 한 번만 표시됩니다. 기기 키를 잃어버렸을 때(예: 새 휴대폰으로 복원한 뒤) 이 코드로 숨긴 오디오와 영상을 다시 열 수 있습니다. 앱을 삭제하거나 데이터를 지우면 숨긴 파일도 삭제되므로, 삭제하기 전에 숨김을 해제하세요.

**백업과 복원**
- **「다운로드 백업」**은 다운로드 목록, 폴더, 설정을 파일 하나에 저장합니다. 비밀번호와 쿠키는 들어 있지 않습니다. **「백업에서 복원」**은 이를 되돌리고 현재 내용과 합칩니다. 다운로드한 파일은 백업에 들어 있지 않습니다. 완료된 다운로드는 해당 파일에 다시 연결되고, 끝나지 않은 다운로드는 일시중지된 상태로 돌아옵니다.

**브라우저와 로그인**
- **앱 안의 브라우저**(더보기 > 브라우저, Android와 iOS): 주소 표시줄과 뒤로 / 앞으로 / 새로 고침이 있습니다. 여기서 연 파일이나 동영상은 페이지의 로그인 정보와 함께 추가 대화상자로 넘어갑니다.
- **브라우저로 로그인**(설정 > 네트워크 > 사이트 로그인): 사이트에 한 번 로그인하면 그 사이트의 다운로드가 해당 세션을 사용합니다. 사이트 로그인을 삭제하면 그 사이트에 대한 브라우저 쿠키도 지워집니다.

**다운로드**
- **연결 수 자동 선택:** FetchJet은 4개의 연결로 시작해 속도가 계속 오르는 동안 연결을 늘리고, 사이트마다 잘 맞았던 설정을 기억합니다.
- **클립 시간이 정확해졌습니다:** 이제 클립은 시작과 끝에 지정한 시간에 정확히 시작하고 끝나며, 시작 / 끝에 초 단위 소수(12.500)도 입력할 수 있습니다. 이전에는 자르는 위치가 가장 가까운 키프레임으로 옮겨져서, 클립이 늦게 시작하거나(시작 12가 12초의 끝에서 시작) 일찍 시작했습니다(11.5가 11에서 시작). 클립 기능이 생긴 뒤로 모든 플랫폼에서 있던 문제입니다.
- **재개에 다운로드 화살표**(⬇)가 ▶ 대신 표시되어, 더 이상 동영상 재생처럼 보이지 않습니다. 이제 ▶는 완료된 파일을 재생할 때만 쓰입니다.
- **Udemy 강좌 전체**를 받으면 강좌 파일도 함께 받습니다. PDF, 전자책, 슬라이드, 코드 강의와 강의에 첨부된 자료가 각각 해당 강의 바로 뒤에 놓입니다.
- **세부 정보**에 출처 링크가 다시 표시됩니다. 로그인 정보나 토큰이 담긴 링크는 대신 안내 문구가 표시됩니다.
- 모든 플랫폼에 **새 앱 아이콘**이 적용됩니다.

**보안과 안전**
- 끝나지 않았거나 실패한 다운로드를 「파일도 삭제」로 지울 때, 같은 이름을 가진 예전 파일을 더 이상 삭제하지 않습니다. 백업에서 복원한 파일을 지울 때는 먼저 그것이 정말 그 다운로드의 파일인지 확인합니다.
- 제자리로 옮기지 못한 다운로드가 최종 이름으로 잘린 파일을 남기지 않으며, 마지막에 크기가 맞지 않아도 이미 받은 부분을 버리지 않습니다.
- 7z와 RAR 압축 파일은 풀기 전에 검사합니다(링크 없음, 폴더 밖으로 나가는 경로 없음, 크기 제한). 압축 파일 비밀번호도 더 이상 다른 프로그램에 보이지 않습니다.
- 브라우저 확장 프로그램과의 로컬 연결에는 항상 페어링이 필요합니다. 자동화 API는 사용자만 켤 수 있으며 API를 통해서는 켤 수 없습니다.
- 잠시 복호화할 수 없었던 설정이 더 이상 확장 프로그램 페어링을 덮어쓰지 않습니다.

**Android**
- **「클립만」이 다시 작동합니다:** 1.5.0부터 Android의 「클립만」은 모든 사이트에서 「ffmpeg exited with code 8」로 실패했습니다. 앱용으로 작게 만든 ffmpeg에 네트워크 기능이 없었기 때문입니다. 이제 ffmpeg가 다시 사이트에서 동영상의 해당 부분을 읽으며, 혹시 그것이 실패하면 오류를 내는 대신 동영상 전체를 받아 정확히 자릅니다.
- **동영상 조각 합치기:** 1.5.0부터 동영상을 조각으로 보내는 일부 사이트(HLS)에서 「dimensions not set」으로 실패했습니다. 수정했습니다.
- 휴대폰에서 정확히 자른 클립이 더 이상 동영상의 해당 부분보다 훨씬 크지 않습니다(작은 동영상의 5초 클립이 1.6 MB였습니다).
- 플레이어에서 화면 양옆 가장자리를 밀면 뒤로 가기 대신 음량이나 밝기가 바뀌고, 뒤로 가기는 열린 메뉴를 먼저 닫은 다음 플레이어를 닫습니다.
- 다른 앱이나 웹페이지에서 연 링크는 항상 추가 대화상자를 먼저 보여 주고, 다른 앱에서 연 torrent 파일은 먼저 확인하며, 배터리 관련 질문은 한 번만 합니다.

**Windows, macOS, Linux**
- 플레이어와 PDF 라이브러리는 FetchJet 자체 폴더에서만 불러오며, 현재 폴더나 PATH에서는 절대 불러오지 않습니다.
- macOS와 Linux: 업데이트와 임시 파일은 사용자만 열 수 있는 폴더를 쓰고, 업데이트는 설치 직전에 한 번 더 검사합니다.
- 「오디오 자르기」 선택 화면에서 두 옵션이 모두 전체 너비로 표시됩니다.

**iOS**
- **「클립만」:** 클립이 재생되지 않는 아주 작은 파일로 저장될 수 있었습니다. 이제 앱이 이를 알아채고 동영상 전체를 받아 정확히 자릅니다.
- 앱 안의 브라우저는 닫으면 소리를 멈추고 메모리를 비웁니다.

**브라우저 확장 프로그램 3.8.0**
- **FetchJet에서 열기:** 페이지 다운로드 버튼 옆의 화살표와 「FetchJet에서 열기」 줄이 페이지 링크를 바로 앱으로 보내고, 화질은 앱에서 고릅니다. 화질 목록을 불러올 수 없는 페이지(예: Udemy 강의)에서도 쓸 수 있습니다.
- **FetchJet을 바로 열기:** 로컬 브리지 없이 링크를 앱에 넘기는 새 옵션입니다.
- **Canva:** 재생 중인 동영상마다 다운로드 버튼이 붙고 페이지 이름으로 저장됩니다. 영상과 소리는 하나의 파일로 저장됩니다.
- **YouTube 홈페이지:** 마우스를 올리면 재생되는 동영상의 버튼이 마우스를 그 위로 옮길 때 더 이상 깜박이지 않고, 항상 마우스 아래에 있는 동영상의 버튼이 됩니다. 이전에는 사라졌다가 다시 나타났고, 다른 동영상에 첫 번째 동영상의 화질을 보여 줄 수 있었습니다.
- **Udemy:** 강의 스트림의 이름이 무작위 코드 대신 강의 이름으로 붙습니다.
- **더 안전해졌습니다:** 확장 프로그램 자체 페이지만 설정을 바꿀 수 있고, 페이지의 쿠키는 같은 사이트에만 보내며, Udemy 강좌 읽기는 udemy.com에서만 작동합니다.

**그 밖의 개선**
- 숨김 화면에서 다운로드를 길게 누르면 메뉴가 열립니다. 이제 모든 목록이 하나의 공통 행 메뉴를 쓰며, 메뉴는 섹션으로 나뉘고 「기본」이 맨 앞에 옵니다.
- Android: 다른 FetchJet 설치본이 받은 파일을 읽을 수 없을 때, FetchJet이 조용히 실패하는 대신 「모든 파일에 대한 접근 허용」 페이지를 엽니다.
- 추가 대화상자에서 「숨겨서 다운로드」 스위치가 없어졌습니다.
