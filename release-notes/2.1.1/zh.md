## 2.1.1 新功能

**媒体播放器**
- **新增：** 在所有平台上都能直接在 FetchJet 里播放已下载完成的音频和视频：行上有播放按钮，整个文件夹、播放列表或分组可以一键“播放”，播放队列带上一个 / 下一个和列表，可调速度，按住可 2x 播放。会记住上次播放的位置。
- **简洁的控制栏：** 控件浮在视频上方，3 秒后自动隐藏。一条细的进度条，加上一小行，包含速度、**自动播放** 开关和 **CC**。视频暂停时，或关闭自动播放后下一个在等待时，画面中间会显示一个大大的 ▶。
- **自动播放：** 打开时，下一项会自动开始；关闭时，下一项加载后保持暂停。
- **字幕：** CC 菜单会列出视频内的字幕、视频旁边的字幕文件（你的语言排在前面）以及“打开字幕文件…”（SRT、VTT、ASS）。每个下载会记住各自的选择。字幕显示在底部，控件出现时会移到控件上方。字幕开启时，CC 图标显示为实心。
- **手机和平板：** 在右半边上下滑动调节音量，在左半边上下滑动调节亮度（仅限播放器内）。
- **电脑：** 音量滑块最高可到 200%，带静音按钮，并支持全屏。在 Windows、macOS 和 Linux 上，播放器组件只在第一次播放时下载，会显示进度，准备好后文件会自动打开。

**剪切、提取和压缩**
- **剪切视频：** 从行菜单或详情中打开，可按时间剪切，也可在时间轴上剪切。时间轴用起来像视频编辑器：时间刻度固定，拖动或滚动来移动，可从几秒缩放到整段视频，拖柄到边缘时时间轴会自动滚动，还有缩略图和一条细滚动条。剪出的片段是一个新文件，显示在原视频下方。
- **剪切音频：** 音频文件也能用同样的方式剪切，时间轴上显示声波。MP3 片段按源文件的码率重新编码，不会损失音质，文件也不会变大。
- **提取音频：** 不重新编码，把视频的音轨另存为单独的文件。
- **删除原文件：** 如果还没有从某个文件生成过其他内容，剪切和压缩会提供“删除原文件”选项。这样新文件就成为主下载：可以给它添加字幕（时间轴跟随片段），也可以再次剪切或压缩。删除一个下载时，从它生成的片段和副本也会一起删除，确认提示会说明有多少个。

**PDF 阅读器**
- **新增：** 直接在 FetchJet 中打开 PDF 文件：页面从上到下排列，显示页码并可“跳到页”，适合宽度，缩放，并会记住你上次读到的页面。Android 和 iOS 使用系统自带的 PDF 引擎；Windows、macOS 和 Linux 第一次使用时会下载一个小型 PDF 组件。可在设置中选择使用应用内阅读器、系统应用，或每次询问。

**隐藏下载**
- **新增：** 可以用 4 到 6 位数字的 PIN 或图案隐藏下载、播放列表或文件夹分组（更多 > 已隐藏）。被隐藏的项目会从列表、图库和文件管理器中消失，它们的文件会移入应用的私有文件夹。隐藏是即时的，文件移动期间会显示一行进度。取消隐藏后，文件会回到原来的文件夹。
- **音频和视频会加密：** 你隐藏的音频和视频会用绑定设备的密钥加密，文件名会被打乱，只在应用的播放器中播放时才解密。其他类型的文件只是被移到看不到的地方。第一次使用时会有提示说明这一点。
- **离开应用后会遮住界面：** 回来时需要指纹、Face ID、Windows Hello 或 PIN 验证，正在播放的隐藏视频会关闭。
- **新下载以隐藏状态开始：** 前提是从“已隐藏”界面（+ 按钮）开始下载。隐藏的下载不会显示通知。
- **忘记 PIN：** 用手机或电脑自带的锁确认身份，然后设置新的 PIN。隐藏的文件会保留。Linux 上不可用。
- **恢复码：** 整个保险库一个码，只显示一次。设备密钥丢失时（例如换新手机并还原之后），可以用它重新打开隐藏的音频和视频。删除应用或清除其数据会同时删除隐藏的文件，所以卸载前请先取消隐藏。

**备份与还原**
- **“备份下载列表”** 会把你的下载列表、文件夹和设置保存到一个文件中，不包含密码和 Cookie。**“从备份还原”** 会把它们恢复，并与现有内容合并。已下载的文件不在备份里：已完成的下载会重新关联到各自的文件，未完成的下载会以暂停状态恢复。

**浏览器与登录**
- **应用内浏览器**（更多 > 浏览器，Android 和 iOS）：带地址栏、后退 / 前进 / 刷新；在里面打开的文件或视频会带着该页面的登录状态进入添加对话框。
- **用浏览器登录**（设置 > 网络 > 网站登录）：在某个网站登录一次，之后它的下载都会使用这个会话。删除该网站登录时，也会清除浏览器中该网站的 Cookie。

**下载**
- **连接数自动选择：** FetchJet 先用 4 个连接开始，只要速度还在提升就继续增加，并记住每个网站最合适的连接数。
- **片段时间更精确：** 片段现在会准确地从“从”开始、在“到”结束，“从” / “到”也支持小数秒（12.500）。以前片段可能开始得晚（从 12 实际在第 12 秒末才开始），也可能开始得早（11.5 从 11 开始），因为剪切点会移到最近的关键帧。自从加入片段功能以来，所有平台都有这个问题。
- **继续下载显示下载箭头**（⬇）而不是 ▶，不再像是在播放视频。▶ 现在只用于播放已完成的文件。
- **Udemy 整门课程** 也会带上课程文件：PDF、电子书、幻灯片和代码类课时，以及课时附带的资料，每个都紧跟在对应课时之后。
- **详情** 重新显示来源链接；如果链接中带有登录信息或令牌，则显示一条说明代替。
- 所有平台都换上了 **新的应用图标**。

**安全**
- 使用“同时删除文件”移除未完成或失败的下载时，不会再删掉你同名的旧文件。删除从备份还原的文件前，会先确认它确实属于这个下载。
- 无法移动到目标位置的下载，不会再以最终文件名留下一个不完整的文件；结束时大小不对，也不会再丢弃已下载的部分。
- 解压 7z 和 RAR 压缩包前会先检查（不允许链接，不允许跳出文件夹的路径，有大小限制），压缩包密码也不再对其他程序可见。
- 与浏览器扩展的本地连接始终需要配对；自动化 API 只能由你本人打开，不能通过 API 本身打开。
- 设置暂时无法解密时，不会再替换掉扩展的配对。

**Android**
- **“只下载片段”恢复正常：** 从 1.5.0 起，Android 上的“只下载片段”在所有网站都会报错 "ffmpeg exited with code 8"，因为为应用精简编译的 ffmpeg 没有网络访问能力。现在 ffmpeg 又能直接从网站读取视频的对应部分；万一失败，应用会下载整个视频再精确剪切，而不是直接报错。
- **合并视频分段：** 从 1.5.0 起，一些分段发送视频（HLS）的网站会报错 "dimensions not set"。已修复。
- 在手机上精确剪切的片段不会再比视频中对应的部分大很多（以前一个小视频的 5 秒片段有 1.6 MB）。
- 在播放器中，在左右边缘滑动会调节音量或亮度，而不是触发返回；返回键会先关闭打开的菜单，再关闭播放器。
- 从其他应用或网页打开的链接总是先显示添加对话框，从其他应用打开的种子文件会先经过检查，电池相关的提问只会问一次。

**Windows、macOS 和 Linux**
- 播放器和 PDF 组件只从 FetchJet 自己的文件夹加载，绝不会从当前文件夹或 PATH 加载。
- macOS 和 Linux：更新和临时文件使用只有你自己能打开的文件夹，并且在安装更新之前会再检查一次。
- “剪切音频”的选择界面中，两个选项都以完整宽度显示。

**iOS**
- **只下载片段：** 片段有时会被保存成一个无法播放的极小文件。现在应用会发现这种情况，改为下载整个视频并精确剪切。
- 关闭应用内浏览器时，它会停止声音并释放内存。

**浏览器扩展 3.8.0**
- **在 FetchJet 中打开：** 页面下载按钮旁的箭头，以及一行“在 FetchJet 中打开”，可立即把页面链接发送到应用，并在应用里选择画质。在无法列出画质的页面（例如 Udemy 课程）上也能使用。
- **直接打开 FetchJet：** 新选项，不经过本地桥接，直接把链接交给应用。
- **Canva：** 每个正在播放的视频都会出现下载按钮，以所在页面命名；视频和声音保存为同一个文件。
- **YouTube 首页：** 鼠标悬停就会播放的视频，其上的按钮在你把鼠标移过去时不再闪烁，并且始终对应鼠标下方的那个视频。以前按钮会消失再出现，还可能在另一个视频上显示第一个视频的画质。
- **Udemy：** 课时视频流以课时名称命名，而不是随机代码。
- **更安全：** 只有扩展自己的页面才能修改它的设置，页面的 Cookie 只会发送给同一个网站，Udemy 课程读取只在 udemy.com 上生效。

**其他改进**
- 在“已隐藏”界面长按某个下载会打开菜单。所有列表现在共用同一个行菜单，按分区排列，“主要”排在最前。
- Android：如果文件由另一次安装的 FetchJet 下载而无法读取，FetchJet 现在会打开“允许访问所有文件”页面，而不是静默失败。
- 添加对话框中不再有“以隐藏方式下载”开关。
