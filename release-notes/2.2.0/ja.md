## 2.2.0 の新機能

**動画を結合**
- **新機能：** 完了した動画を 2 本以上選び、選択バーの **結合** を押します。順番を決め（古いものが先、上へ / 下へ移動）、新しい動画に名前を付けると、FetchJet が進行状況と残り時間を表示しながら 1 つのファイルにまとめます。
- **高速、変換なし：** 動画はそのままつなげるので、スマートフォンでも結合は数秒で終わります。これはすべての動画の形式とサイズが同じときだけ使えます。違う動画には印が付き、結合は待機します。
- **同じ名前：** そのフォルダーで名前がすでに使われているときは、コピーとして保存、上書き、キャンセルから選べます。

**Windows 7、8、8.1**
- **新機能：** FetchJet に Windows 7、8、8.1（64 ビット）向けの版ができました。専用のセットアップ **FetchJet-2.2.0-Setup-Windows-7-8-8.1.exe** で、ダウンロード、動画、トレント、プレーヤー、PDF リーダーが使えます。Windows 7 で動画をダウンロードするには、更新プログラム（SP1 と 2016 年の更新プログラムのロールアップ）が必要です。
- **ブラウザー拡張機能：** Windows 7、8、8.1 向けの最後の Firefox である Firefox 115 でも動きます。

**プレーヤー（Android と iOS）**
- **ドラッグでシーク：** 動画の上で左右にドラッグします。指を置いている間は一時停止し、映像が指に合わせて動きます。中央のボックスに新しい時間と移動した量が表示されます。指を離すと、そこから再生します。
- **Android：** プレーヤーの端からの「戻る」ジェスチャーがまた使えるようになりました。

**ダウンロード**
- **同じ名前で上書きしない：** そのフォルダーで別のダウンロードがすでに使っている名前の新しいダウンロードは、相手がまだダウンロード中でも、番号付きの名前になります。以前は、同じタイトルの別の動画がまだダウンロード中に追加した動画が、そのファイルを置き換えることがありました。
- **更新が速く：** アプリの更新は、普段のダウンロードと同じく、FetchJet 自身のエンジンで複数の接続を使ってダウンロードするようになりました。2.2.0 の次の更新から適用されます（2.2.0 自体は従来の方法でダウンロードします）。
- **「HTTP Error 410」で止まっていた動画：** サイトが動画ファイルのリンクを拒否したとき、FetchJet は失敗せずに、そのサイトのストリームから同じ画質でダウンロードするようになりました。
- **このページのファイルを探す** がより多く見つけます：画像のすべてのサイズ、ページの属性に入っているリンク、ファイル名はないがファイルを指しているリンク。
- **プレイリストとフォルダーの並べ替え：** プレイリストやフォルダーのページでは、並べ替えが名前の横に表示されます。ページはその順に並び、すべて再生も表示どおりの順で再生します。選んだ順序はアプリ全体で共通で、再起動後も保たれます。

**修正**
- **Android：** スマートフォンの選択バーは件数と ✕ を定位置に保ち、ボタンは押しつぶされて切れることなく 1 行でスクロールします。
- **Windows：** トレイから戻したウィンドウが、マウスを上に動かすまで空白や白のままになることがありました。今は全体がきちんと再描画されます。
- **Linux：** クリップボードの監視で、同じコピー済みリンクを何度も読み取らなくなりました。
