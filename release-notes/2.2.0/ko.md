## 2.2.0의 새로운 기능

**동영상 합치기**
- **새 기능:** 완료된 동영상을 두 개 이상 선택하고 선택 막대에서 **합치기**를 누르세요. 순서를 정하고(오래된 것부터, 위로 / 아래로 이동) 새 동영상의 이름을 정하면 FetchJet이 진행률과 남은 시간을 보여 주며 하나의 파일로 합칩니다.
- **빠르고 변환 없음:** 동영상을 있는 그대로 이어 붙이므로 휴대폰에서도 합치기는 몇 초면 끝납니다. 모든 동영상의 형식과 크기가 같을 때만 됩니다. 다른 동영상은 표시되고 합치기는 기다립니다.
- **같은 이름:** 그 폴더에서 이름이 이미 쓰이고 있으면 직접 고릅니다: 사본으로 저장, 덮어쓰기 또는 취소.

**Windows 7, 8, 8.1**
- **새 기능:** 이제 FetchJet에 Windows 7, 8, 8.1(64비트)용 버전이 있으며 전용 설치 파일 **FetchJet-2.2.0-Setup-Windows-7-8-8.1.exe**를 씁니다: 다운로드, 동영상, 토렌트, 플레이어, PDF 리더. Windows 7에서 동영상을 다운로드하려면 업데이트(SP1과 2016 업데이트 롤업)가 필요합니다.
- **브라우저 확장 프로그램:** Windows 7, 8, 8.1용 마지막 Firefox인 Firefox 115에서도 작동합니다.

**플레이어 (Android 및 iOS)**
- **드래그로 이동:** 동영상 위에서 왼쪽이나 오른쪽으로 드래그하세요. 손가락을 대고 있는 동안 일시정지되고 화면이 손가락을 따라갑니다. 가운데 상자에 새 시간과 이동한 만큼이 표시됩니다. 손가락을 떼면 그 지점부터 재생됩니다.
- **Android:** 플레이어 가장자리에서 뒤로 가기 제스처가 다시 작동합니다.

**다운로드**
- **같은 이름은 절대 덮어쓰지 않음:** 그 폴더에서 다른 다운로드가 이미 쓰는 이름의 새 다운로드는, 그 다운로드가 아직 진행 중이어도 번호가 붙은 이름을 받습니다. 전에는 같은 제목의 다른 동영상이 아직 다운로드되는 동안 추가한 동영상이 그 파일을 바꿔 버릴 수 있었습니다.
- **더 빠른 업데이트:** 앱 업데이트가 이제 여러분의 다운로드와 똑같이 FetchJet 자체 엔진으로 여러 연결을 통해 다운로드됩니다. 2.2.0 다음 업데이트부터 적용됩니다(2.2.0 자체는 여전히 예전 방식으로 다운로드됩니다).
- **이 페이지에서 파일 찾기**가 더 많이 찾습니다: 그림의 모든 크기, 페이지 속성에 담긴 링크, 파일 이름은 없지만 파일을 가리키는 링크.

**수정 사항**
- **Android:** 휴대폰의 선택 막대가 개수와 ✕를 제자리에 두고, 버튼들은 눌리고 잘리는 대신 한 줄에서 스크롤됩니다.
- **Windows:** 트레이에서 다시 연 창이 마우스를 위로 옮길 때까지 비어 있거나 흰색으로 남을 수 있었습니다. 이제 전체가 다시 그려집니다.
- **Linux:** 클립보드 감시가 더 이상 같은 복사된 링크를 계속해서 읽지 않습니다.
