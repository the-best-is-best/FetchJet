## 2.2.0 新功能

**合并视频**
- **新增：** 选择两个或更多已完成的视频，在选择栏中点 **合并**。排好顺序（最早的在前，可上移 / 下移），给新视频命名，FetchJet 会把它们合成一个文件，并显示进度和剩余时间。
- **快速，不转换：** 视频按原样拼接，所以即使在手机上，合并也只需几秒。只有所有视频的格式和尺寸都相同时才行；不同的视频会被标出，合并会等待。
- **同名：** 如果该文件夹中已有这个名称，由你选择：另存为副本、覆盖或取消。

**Windows 7、8 和 8.1**
- **新增：** FetchJet 现在有适用于 Windows 7、8 和 8.1（64 位）的版本，带有自己的安装程序 **FetchJet-2.2.0-Setup-Windows-7-8-8.1.exe**：下载、视频、种子、播放器和 PDF 阅读器。Windows 7 需要安装其更新（SP1 和 2016 更新汇总）才能下载视频。
- **浏览器扩展：** 也支持 Firefox 115，即适用于 Windows 7、8 和 8.1 的最后一个 Firefox 版本。

**播放器（Android 和 iOS）**
- **拖动快进快退：** 在视频上向左或向右拖动。手指按住时视频暂停，画面跟随手指移动；中间的框显示新的时间和移动了多少。松开手指，就从那里开始播放。
- **Android：** 从播放器边缘的返回手势又能用了。

**下载**
- **同名文件绝不被覆盖：** 新下载的名称如果已被该文件夹中的另一个下载使用（即使那个还在下载），会得到带编号的名称。以前，在另一个同标题视频仍在下载时添加的视频，可能会替换掉那个文件。
- **更新更快：** 应用更新现在用 FetchJet 自己的引擎通过多个连接下载，和你的下载一样。从 2.2.0 之后的更新开始生效（2.2.0 本身仍按旧方式下载）。
- **在此页面查找文件** 能找到更多：图片的所有尺寸、保存在页面属性中的链接，以及没有文件名但指向文件的链接。

**修复**
- **Android：** 手机上的选择栏会把数量和 ✕ 固定在原位，按钮在一行中滚动，而不是被挤压截断。
- **Windows：** 从托盘恢复的窗口可能一直空白或发白，直到鼠标移到上面。现在会完整重绘。
- **Linux：** 监视剪贴板时不再反复读取同一个已复制的链接。
