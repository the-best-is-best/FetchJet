## 1.6.0의 새로운 기능

**더 똑똑해진 추가 창**
- **링크를 보고 FetchJet이 엔진을 고릅니다:** 파일, 마그넷 링크, 알려진 동영상 사이트는 알아서 Direct, Torrent, Media로 갑니다. 먼저 링크를 한 번 확인하며("링크 확인 중…"), Direct / Media 선택은 동영상이 있는 페이지이거나 확인하지 못한 링크일 때만 나타납니다.
- **글자를 칠 때마다 확인하지 않습니다:** 입력을 멈추면 확인이 시작됩니다(붙여넣은 링크는 즉시). 링크를 바꾸면 이전 읽기가 취소되므로, 예를 들어 피어를 찾지 못하는 마그넷에서도 창이 "이름 찾는 중…"에 멈춰 있지 않습니다.

**이 페이지에서 파일 찾기**
- **새 기능:** 페이지 링크를 붙여넣고 "이 페이지에서 파일 찾기"를 사용하세요. FetchJet이 페이지의 파일(이미지, 링크, 일반 텍스트로 적힌 주소)을 나열합니다. 파일 이름이 없는 링크는 서버에 실제 이름과 크기를 물어봅니다. 원하면 그 페이지가 링크한 페이지도 한두 단계 아래까지 읽습니다.
- **읽는 동안 결과 표시:** 페이지를 읽는 동안 파일이 나타나고, "읽기 중지"를 누르면 찾은 것은 그대로 남습니다.
- **받을 것을 고르기:** 파일 형식은 해당 파일을 숨기거나 보여 주는 버튼이며, 숨긴 파일은 다운로드되지 않습니다. 각 줄에는 형식(ZIP, MP3, PNG…)이 표시됩니다.
- **그룹으로 저장:** 파일은 페이지 이름을 딴 폴더와 그룹에 저장됩니다. 나중에 "새 파일 확인"을 누르면 이미 가진 파일에 표시하고 선택할 수 없게 잠급니다("N개는 이전에 다운로드함").
- **GitHub 릴리스 페이지**는 한 번의 요청으로 읽습니다.
- **읽을 수 없는 페이지:** 사이트가 거부한 페이지(확인 또는 차단)는 개수를 셉니다. JavaScript로 링크를 만드는 페이지는 이름을 알려 주고, 브라우저에서 열어 확장 프로그램의 '모든 링크 다운로드'를 사용하라고 안내합니다.

**재생목록과 자막**
- **재생목록:** 이전에 다운로드한 동영상에는 표시가 붙고 개수가 나옵니다("N개는 이전에 다운로드함"). 그룹으로 저장한 재생목록은 새 동영상이 있는지 확인할 수 있습니다.
- **자막:** "영상에 삽입" 또는 "별도 파일"을 고른 뒤 SRT 또는 VTT를 고릅니다. 언어는 하나씩 요청하며, 사이트가 잠깐 거부한 언어는 다시 요청합니다. 완료된 동영상에도 상세 정보나 줄 메뉴에서 자막을 추가할 수 있습니다.
- **"기기로 보내기"가 자막을 유지합니다:** 다른 기기로 보낸 완성된 영상에서도 "자막 추가"를 쓸 수 있고, 파일에 이미 있는 언어를 알며, 옆에 있는 자막 파일도 함께 전송됩니다.

**동영상**
- **Google Drive:** 모든 Drive 파일 링크를 바로 다운로드하며, 소유자가 다운로드를 끈 파일은 그렇다고 알려 줍니다.
- **보호된 동영상:** DRM으로 보호된 동영상은 화질 목록 전에 그렇다고 알려 주며, 나중에 실패하지 않습니다.
- **어디서나 재생되는 동영상:** 이 스위치(이제 설정 > 미디어 도구에 있으며 Android에서도 사용 가능)로 모든 TV와 플레이어에서 열리는 H.264 + AAC 파일 또는 더 작은 AV1 / VP9 파일을 선택합니다.

**설정**
- **새로 정리했습니다:** 다운로드(위치, 연결, 대기열), 새 속도 제한 페이지(프리셋, 유휴 시 제한, 예약), 새 파일 및 폴더 페이지(형식별 정리, 폴더별 그룹화, 압축 풀기, 휴지통, 검사, 사이트별 폴더).

**속도**
- 큰 파일은 기본으로 최대 32개 연결을 사용합니다.
- 20초 동안 데이터를 받지 못한 요청은 버리고 다시 요청하므로, 멈춘 연결 하나 때문에 다운로드가 1분씩 멈추지 않습니다.
- 짧고 빠른 전송에서는 느린 연결이 더 빨리 교체됩니다.
- macOS는 사이트당 64개 연결을 허용하므로, 같은 사이트의 두 번째 다운로드가 더 이상 기다리지 않습니다.

**그 밖의 개선**
- "다운로드 완료 시" 동작이 압축을 푸는 중인 아카이브나 검사 중인 파일도 기다립니다.
- 이름이 긴 토렌트도 파일 카드가 늘어나지 않으며, 파일 줄에는 파일 이름이 먼저 나옵니다.
- 아랍어와 페르시아어에서도 링크와 폴더 경로가 방향을 유지합니다.
- Android: 백그라운드에서 읽던 재생목록 때문에 앱이 종료되던 문제를 고쳤습니다.
- 데스크톱 창은 표시되거나 크기가 바뀐 뒤 전체가 다시 그려져 그려지지 않은 부분이 남지 않습니다.
- macOS 앱은 macOS 12 이상에서 실행되도록 빌드됩니다.
- **Android: 재설치나 새 휴대폰 뒤에도 목록이 깨지지 않습니다:** 다운로드 목록은 더 이상 백업에서 복원되지 않습니다. 링크가 그 휴대폰에 묶여 있어 다른 곳에서는 읽을 수 없었기 때문입니다. 내려받은 파일은 폴더에 그대로 남습니다.
- **더 분명한 자막 메시지:** 오래된 다운로드의 링크를 읽을 수 없을 때 "자막 추가"가 영상에 자막이 없다고 하는 대신 자막을 읽지 못했다고 알려 줍니다.
