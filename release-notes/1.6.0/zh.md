## 1.6.0 新功能

**更聪明的添加窗口**
- **FetchJet 根据链接选择引擎：** 文件、磁力链接或已知的视频网站会自动进入 Direct、Torrent 或 Media。它会先检查一次链接（“正在检查链接…”），只有带视频的页面，或无法检查的链接，才会显示 Direct / Media 的选择。
- **不再每输入一个字符就检查一次：** 停止输入后才开始检查（粘贴的链接立即检查）。更改链接会取消之前的读取，因此窗口不会再卡在“正在查找名称…”，例如遇到找不到任何用户的磁力链接时。

**在此页面查找文件**
- **新增：** 粘贴页面链接，使用“在此页面查找文件”。FetchJet 会列出页面中的文件：图片、链接和以纯文本写出的地址。对没有文件名的链接，它会向服务器询问真实名称和大小。如果你需要，它还会读取该页面链接到的页面，向下一到两层。
- **边读边出结果：** 读取页面时文件会逐步出现，点“停止读取”会保留已找到的文件。
- **选择要下载的内容：** 文件类型是按钮，可隐藏或显示对应文件，隐藏的文件不会被下载。每一行都会显示其类型（ZIP、MP3、PNG…）。
- **保存为一个组：** 文件会保存到以页面命名的文件夹和组中。之后“检查新文件”会标出你已有的文件并将其锁定（“N 个已下载过”）。
- **GitHub 发布页面**只需一次请求即可读取。
- **无法读取的页面：** 被网站拒绝的页面（验证或拦截）会被计数。用 JavaScript 生成链接的页面会被点名，并提示在浏览器中打开它们，使用扩展的“下载所有链接”。

**播放列表和字幕**
- **播放列表：** 你之前下载过的视频会被标记并计数（“N 个已下载过”），保存为组的播放列表可以检查是否有新视频。
- **字幕：** 选择“嵌入视频”或“单独文件”，再选 SRT 或 VTT。语言会逐个请求，网站暂时拒绝的语言会再次请求。你也可以从详情或行菜单中，为已完成的视频添加字幕。
- **“发送到设备”会保留字幕：** 发送到另一台设备的已完成视频，在那里仍可使用“添加字幕”，知道文件里已有哪些语言，旁边的字幕文件也会一起发送。

**视频**
- **Google Drive：** 任何 Drive 文件链接都可直接下载，所有者关闭了下载的文件会如实提示。
- **受保护的视频：** 受 DRM 保护的视频会在画质列表之前就被标明，而不是之后才失败。
- **到处都能播放的视频：** 这个开关（现在位于设置 > 媒体工具，Android 上也有）可选择每台电视和播放器都能打开的 H.264 + AAC 文件，或更小的 AV1 / VP9 文件。

**设置**
- **重新整理：** 下载（位置、连接数、队列）、新的限速页面（预设、空闲限制、计划），以及新的文件和文件夹页面（按类型分类、按文件夹分组、解压、回收站、扫描、按网站设置文件夹）。

**速度**
- 大文件默认最多使用 32 个连接。
- 20 秒收不到数据的请求会被放弃并重新请求，一个卡住的连接不再让下载停滞一分钟。
- 在短而快的传输中，慢连接会更早被替换。
- macOS 每个网站允许 64 个连接，因此来自同一网站的第二个下载不再需要等待。

**其他改进**
- “所有下载完成后”也会等待正在解压的压缩包或正在扫描的文件。
- 名称很长的种子不再撑大文件卡片，其文件行会先显示文件名。
- 阿拉伯语和波斯语中，链接和文件夹路径保持各自的方向。
- Android：在后台读取播放列表不再导致应用崩溃。
- 桌面窗口在显示或调整大小后会完整重绘，不再出现未绘制的区域。
- macOS 应用构建为可在 macOS 12 及更高版本上运行。
- **Android：重装或换手机后不再出现损坏的列表：** 下载列表不再从备份中恢复，因为其中的链接绑定在原手机上，在别处无法读取。你下载的文件仍留在你的文件夹中。
- **更清楚的字幕提示：** 旧下载的链接无法读取时，“添加字幕”会说没能读取字幕，而不是说视频没有字幕。
