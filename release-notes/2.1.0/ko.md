## 2.1.0의 새로운 기능

**숨긴 다운로드**
- **새 기능:** 다운로드, 재생목록, 폴더 그룹을 4~6자리 PIN 뒤에 숨길 수 있습니다(더보기 > 숨김). 숨긴 항목은 목록, 갤러리, 파일 관리자에서 사라지고 파일은 앱의 비공개 폴더로 옮겨집니다. 숨기기는 즉시 끝나며, 파일을 옮기는 동안 진행 상황이 한 줄로 표시됩니다. 숨김을 해제하면 파일이 원래 폴더로 돌아갑니다.
- **오디오와 영상은 암호화됩니다:** 숨긴 오디오와 영상은 기기에 묶인 키로 암호화되고 파일 이름은 뒤섞이며, 재생하는 동안에만 복호화됩니다. 다른 형식의 파일은 눈에 띄지 않는 곳으로 옮겨질 뿐입니다. 처음 숨길 때 안내 메시지가 이를 설명합니다.
- **새 다운로드는 숨긴 상태로 시작합니다:** 숨김 화면(+ 버튼)에서 시작한 경우입니다. 숨긴 다운로드는 알림을 표시하지 않습니다.
- **PIN을 잊었을 때:** 휴대폰이나 컴퓨터의 잠금(지문, 화면 잠금, Windows Hello, Face ID)으로 확인한 뒤 새 PIN을 설정합니다. 숨긴 파일은 그대로 남습니다. Linux에서는 사용할 수 없습니다.
- **복구 코드:** 보관함 전체에 코드 하나이며 한 번만 표시됩니다. 기기 키를 잃어버렸을 때(예: 새 휴대폰으로 복원한 뒤) 이 코드로 숨긴 오디오와 영상을 다시 열 수 있습니다. 앱을 삭제하거나 데이터를 지우면 숨긴 파일도 삭제되므로, 삭제하기 전에 숨김을 해제하세요.

**백업과 복원**
- **「다운로드 백업」**은 다운로드 목록, 폴더, 설정을 파일 하나에 저장합니다. 비밀번호와 쿠키는 들어 있지 않습니다. **「백업에서 복원」**은 이를 되돌리고 현재 내용과 합칩니다. 다운로드한 파일은 백업에 들어 있지 않습니다. 완료된 다운로드는 해당 파일에 다시 연결되고, 끝나지 않은 다운로드는 일시중지된 상태로 돌아옵니다.

**브라우저 확장 프로그램 3.8.0**
- **FetchJet에서 열기:** 페이지 다운로드 버튼 옆의 새 화살표와 「FetchJet에서 열기」 줄이 페이지 링크를 바로 앱으로 보내고, 화질은 앱에서 고릅니다. 화질 목록을 불러올 수 없는 페이지(예: Udemy 강의)에서도 쓸 수 있습니다.
- **FetchJet을 바로 열기:** 로컬 브리지 없이 링크를 앱에 넘기는 새 옵션입니다.

**그 밖의 개선**
- 숨김 화면에서 다운로드를 길게 누르면 메뉴가 열립니다. 이제 모든 목록이 하나의 공통 행 메뉴를 씁니다.
- Android: 다른 FetchJet 설치본이 받은 파일을 읽을 수 없을 때, FetchJet이 조용히 실패하는 대신 「모든 파일에 대한 접근 허용」 페이지를 엽니다.
- 추가 대화상자에서 「숨겨서 다운로드」 스위치가 없어졌습니다.
