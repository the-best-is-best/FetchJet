## 1.4.1의 새로운 기능

**다운로드**
- **FTP 및 FTPS 다운로드(신규):** ftp://, ftps://, ftpes://로 시작하는 링크를 이제 다른 직접 링크처럼 다운로드합니다. 서버가 허용하면 여러 부분으로 나누어 받고 이어받기도 됩니다. 로그인 정보는 링크에 넣거나, 설정 > 네트워크 > 사이트 로그인에 저장하거나, 익명 서버라면 비워 두면 됩니다. 참고: FTP 링크는 프록시를 거치지 않습니다. 데스크톱 앱에서 TLS를 사용하는 FTP는 시스템의 curl로 받습니다. TLS를 사용하는 FTP는 아직 iPhone과 iPad에서 사용할 수 없습니다.
- **서버에서 바뀌는 파일:** 다운로드 중에 서버의 파일이 교체되면 FetchJet이 알아챕니다. 뒤섞인 손상된 파일을 저장하는 대신 분명한 메시지와 함께 다운로드가 멈추고, 재개하면 새 버전을 받습니다.
- **끝에서 더 이상 기다리지 않음:** 다운로드의 끝이 느린 연결 하나를 기다리지 않습니다. 끝에서 느려진 연결은 교체됩니다.
- **저장 전 검사:** 추가 대화상자에 체크섬(SHA-256 또는 MD5)을 붙여넣거나, 서버 자체의 체크섬 헤더에 맡길 수 있습니다. 일치하지 않는 파일은 저장되지 않습니다. ZIP 파일은 항목별로 검사하며, 손상된 부분은 한 번 다시 받습니다.
- **서버 제한 기억:** 연결을 몇 개만 허용하는 사이트는 하루 동안 기억되어, 다음 다운로드가 거부당하는 수의 연결로 시작하지 않습니다. 403 뒤에는 FetchJet이 IPv4로 다시 시도할 수 있습니다(Windows, Android, Linux).
- **링크 테스트:** 추가 대화상자의 버튼이 다운로드하지 않고도 링크가 작동하는지, 크기가 얼마인지, 이어받기가 되는지 알려 줍니다.
- **파일 종류별 폴더:** 동영상, 음악, 압축 파일용으로 고른 폴더는 그 종류에만 기억됩니다.
- **목록에서 재생:** 완료된 동영상·오디오 파일에 ▶ 버튼이 표시되어 사용 중인 플레이어로 열 수 있습니다.
- **임의의 파일 이름 없음:** 파일 이름이 없는 링크는 '파일 이름' 칸이 비어 있고, 이름을 입력해야 시작할 수 있습니다.
- **화면에 맞춤:** 데스크톱 창이 이제 작업 표시줄 아래에 일부 가려지지 않고 보이는 화면 안에서 열립니다.

**토렌트**
- **상세 정보:** 공유 비율, 업로드한 양, 조각과 조각 크기, 상태가 표시되는 트래커, 피어, "다시 검사", magnet 링크 복사, 동영상 미리보기를 위한 "처음과 마지막 조각 먼저".
- 실행 중인 토렌트에 **트래커 추가**, 그리고 직접 정한 **비율에서 공유 중지**(설정 > BitTorrent).
- **더 안전하게:** 파일이 토렌트 자체 폴더 밖에 쓰이게 되는 토렌트는 거부됩니다.
- **HTTP 프록시 뒤에서:** UDP 트래커만 있는 토렌트는 거기서 피어를 찾지 못합니다. 설정 > 네트워크와 오류 메시지가 이제 이를 알려 줍니다.

**데스크톱**
- **키보드:** 화살표, Shift, Home / End, Page Up / Down, Enter(Alt+Enter로 상세 정보 열기/닫기), Ctrl+R / P / O / E / N / F / A, Delete, Esc, 단축키 목록은 F1. 아랍어, 페르시아어, 러시아어 키보드에서도 작동하며, 모든 입력란에서 복사 / 붙여넣기도 됩니다.
- **명령줄:** `/d` 링크, `/p` 폴더, `/f` 파일 이름, `/a` 추가 대화상자 없이 일시 중지 상태로 추가, `/n` 창 없이 추가하고 바로 시작, `/s` 대기 중인 모든 항목 시작.
- **컴퓨터를 사용하는 동안에만 속도 제한,** 그리고 **예약된 다운로드를 위해 컴퓨터 깨우기**(Windows).
- **자잘한 개선:** 창 제목에 버전 표시, Esc로 추가 대화상자 닫기, 밝은 테마에서도 읽기 쉬운 파일 형식 배지, 그리고 "기기로 보내기" 제목이 모든 곳에서 번역됩니다.

**오디오**
- **OGG:** YouTube(Opus) 오디오에 OGG를 선택해도 더 이상 다시 인코딩하지 않습니다. 원래 품질과 크기 그대로 바로 저장됩니다.
- **오디오 압축:** 이제 변환과 같은 형식(M4A, MP3, Opus, OGG, FLAC, WAV)을 제공하고, 파일이 OGG이면 OGG를 유지하며, 예상 크기가 실제 크기에 더 가깝습니다.

**브라우저 확장 프로그램 (3.4)**
- **연결:** 브라우저가 아직 앱에 연결되지 않았을 때 확장 프로그램이 끝없이 로딩하지 않고 바로 알려 줍니다("FetchJet을 열고 허용을 누르세요"). 허용을 누르면 화질 목록이 저절로 나타납니다. 브라우저가 "FetchJet을 열까요?"라고 물으면 이제 답할 때까지 탭이 남아 있습니다. 설정 > 브라우저 확장 프로그램에 "모두 해제"가 있습니다.
- **앱이 받을 때까지 브라우저가 다운로드를 보관하고,** 제출한 양식은 브라우저에 남으며, 비공개 창은 자체 쿠키를 사용합니다.
- **링크:** 파일 링크는 페이지 자체의 클릭 코드가 실행된 뒤에 가져오므로, 예전에 403을 내던 사이트도 이제 작동합니다. PDF 링크는 페이지가 다운로드로 표시하지 않는 한 브라우저에서 열립니다. "모든 링크 다운로드"는 다운로드로 표시된 링크와 data-* 속성에 담긴 링크도 찾고, Google Drive에는 "원본 파일" 행이 있습니다.
- **동영상 버튼:** 키보드(Tab, Enter)로 사용할 수 있고, 가장자리로 끌면 그 가장자리에 붙으며, 겹쳐진 동영상 그룹마다 버튼이 하나, 페이지 아래에 숨은 동영상에는 버튼이 없습니다. 사이트별로 숨길 수 있고, Telegram Web은 다운로드할 수 없는 이유를 설명합니다.
- **확장 프로그램이 앱의 테마를 따릅니다:** 팝업, 설정 페이지, 웹 페이지의 다운로드 버튼이 앱처럼 라이트 또는 다크로 표시되며('시스템'은 기기를 따름), 앱이 실행 중이 아닐 때는 브라우저를 따릅니다.

**업데이트**
- **업데이트 창**은 앱의 언어를 따르며, 릴리스 노트도 번역됩니다.
