## 1.4.1의 새로운 기능

- **FTP 및 FTPS 다운로드(신규):** ftp://, ftps://, ftpes://로 시작하는 링크를 이제 다른 직접 링크처럼 다운로드합니다. 서버가 허용하면 여러 부분으로 나누어 받고 이어받기도 됩니다. 로그인 정보는 링크에 넣거나, 설정 > 네트워크 > 사이트 로그인에 저장하거나, 익명 서버라면 비워 두면 됩니다. 참고: FTP 링크는 프록시를 거치지 않습니다. 데스크톱 앱에서 TLS를 사용하는 FTP는 연결 하나만 사용합니다. TLS를 사용하는 FTP는 아직 iPhone과 iPad에서 사용할 수 없습니다.
- **서버에서 바뀌는 파일:** 다운로드 중에 서버의 파일이 교체되면 FetchJet이 이를 알아챕니다. 뒤섞여 손상된 파일을 저장하는 대신 명확한 메시지와 함께 다운로드를 멈추며, "재개"를 누르면 새 버전을 다운로드합니다.
- **마지막에 기다리지 않음:** 다운로드 끝부분에서 느린 연결 하나를 더 이상 기다리지 않습니다. 끝에서 매우 느려진 연결은 교체됩니다.
- **OGG 오디오:** YouTube 오디오(Opus)에 OGG를 선택해도 더 이상 다시 인코딩하지 않습니다. 원본 품질과 크기 그대로 바로 저장됩니다.
- **오디오 압축:** 이제 변환과 같은 형식(M4A, MP3, Opus, OGG, FLAC, WAV)을 제공하고, 파일이 OGG이면 OGG를 유지하며, 예상 크기가 실제 크기에 더 가까워졌습니다.
- **브라우저 확장 프로그램:** 브라우저가 아직 앱에 연결되지 않았으면 끝없이 로딩하는 대신 바로 알려 줍니다("FetchJet을 열고 허용을 탭하세요"). "허용"을 탭하면 새로 고침 없이 화질 목록이 저절로 나타납니다. 오류가 난 뒤에는 동영상 페이지를 새로 고치면 다시 시도합니다.
- **설정 > 브라우저 확장 프로그램:** "모두 해제"는 페어링된 모든 브라우저의 연결을 끊습니다. 각 브라우저는 다음에 다시 "허용"을 요청합니다.
- **업데이트 창:** 앱 언어를 바꾸면 릴리스 노트도 그 언어를 따릅니다.
