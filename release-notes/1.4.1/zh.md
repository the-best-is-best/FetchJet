## 1.4.1 新功能

**下载**
- **FTP 和 FTPS 下载（新增）：** 以 ftp://、ftps:// 或 ftpes:// 开头的链接现在可以像其他直接链接一样下载：分成多个部分下载，服务器允许时还支持续传。登录信息可以写在链接里，也可以保存在 设置 > 网络 > 网站登录 中，匿名服务器则无需填写。须知：FTP 链接不经过代理；在桌面版应用中，基于 TLS 的 FTP 通过系统自带的 curl 获取；iPhone 和 iPad 暂不支持基于 TLS 的 FTP。
- **服务器上发生变化的文件：** 如果文件在下载过程中被服务器替换，FetchJet 会察觉。下载会带着清晰的提示停止，而不是保存一个拼凑损坏的文件，点击继续会下载新版本。
- **结尾不再等待：** 下载的结尾不再等待某一个缓慢的连接。结尾处变慢的连接会被替换。
- **保存前的校验：** 在添加对话框中粘贴校验值（SHA-256 或 MD5），或者让服务器自己的校验值响应头来决定。不匹配的文件不会被保存。ZIP 文件会逐个条目检查，损坏的部分会重新下载一次。
- **记住服务器的限制：** 只允许少量连接的网站会被记住一天，这样下一次下载就不会用它拒绝的连接数开始。遇到 403 后，FetchJet 可以改用 IPv4 重试（Windows、Android 和 Linux）。
- **测试链接：** 添加对话框中的一个按钮，无需下载就能告诉你链接是否可用、大小多少、能否续传。
- **按文件类型分文件夹：** 你为视频、音乐或压缩包选择的文件夹只会针对该类型被记住。

**种子**
- **详情：** 分享率、已上传量、分块和分块大小、带状态的 Tracker、节点、“重新检查”、复制 magnet 链接，以及用于预览视频的“优先下载开头和结尾的分块”。
- 可以向正在运行的种子**添加 Tracker**，也可以在你设定的**分享率时停止分享**（设置 > BitTorrent）。
- **更安全：** 文件将被写到自身文件夹之外的种子会被拒绝。
- **在 HTTP 代理之后：** 只有 UDP Tracker 的种子在那里找不到节点；设置 > 网络 和错误提示现在都会说明这一点。

**桌面版**
- **键盘：** 方向键、Shift、Home / End、Page Up / Down、Enter（Alt+Enter 打开或关闭详情）、Ctrl+R / P / O / E / N / F / A、Delete、Esc，以及用于查看快捷键列表的 F1。它们也适用于阿拉伯语、波斯语和俄语键盘，每个输入框中的复制 / 粘贴同样可用。
- **命令行：** `/d` 链接，`/p` 文件夹，`/f` 文件名，`/a` 不弹出添加对话框、以暂停状态添加，`/n` 不弹出窗口、添加后立即开始，`/s` 开始所有等待中的任务。
- **仅在你使用电脑时限速，** 以及**为计划下载唤醒电脑**（Windows）。
- **一些小改进：** 窗口标题显示版本号，Esc 关闭添加对话框，文件类型徽标在浅色主题下清晰可读，“发送到设备”的标题在各处都已翻译。

**音频**
- **OGG：** 为 YouTube（Opus）音频选择 OGG 不再重新编码。它会立即以原始音质和大小保存。
- **压缩音频：** 现在提供与转换相同的格式（M4A、MP3、Opus、OGG、FLAC、WAV），文件为 OGG 时保持 OGG，预估大小也更接近实际大小。

**浏览器扩展 (3.4)**
- **连接：** 当浏览器尚未连接到应用时，扩展会立刻提示（“打开 FetchJet 并点击允许”），而不是一直加载。点击允许后，画质列表会自动出现。如果浏览器询问“打开 FetchJet？”，标签页现在会保留到你回答为止。设置 > 浏览器扩展 中有“全部取消配对”。
- **浏览器会保留下载，直到应用接收为止，** 你提交的表单会留在浏览器中，隐私窗口使用它自己的 Cookie。
- **链接：** 文件链接会在页面自身的点击代码运行之后再获取，因此以前返回 403 的网站现在可以正常使用。除非页面将 PDF 链接标记为下载，否则它会在浏览器中打开。“下载所有链接”还会找到标记为下载的链接以及保存在 data-* 属性中的链接，Google Drive 则多了一行“原始文件”。
- **视频按钮：** 可用键盘操作（Tab、Enter），拖到边缘时会吸附在边缘，每组叠放的视频只有一个按钮，被页面遮在下面的视频上没有按钮。你可以在某个网站上隐藏它，Telegram Web 会说明为什么无法下载。

**更新**
- **更新窗口**跟随应用的语言，发布说明也已翻译。
