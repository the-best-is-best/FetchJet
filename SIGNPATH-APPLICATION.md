## Before pressing Submit

1. The page named in "Download URL" must say that the project uses SignPath Foundation for code signing. The README section "Code signing policy" says it, but it is not pushed yet. Push first, then apply.
2. Turn on two-factor authentication on GitHub (SignPath asks for it on both accounts).
3. The Windows build runs on a self-hosted runner. Ask SignPath in your first reply if this is allowed; if not, the Windows job has to move to a GitHub-hosted runner.
4. Only the Windows installers (`.msi` and `-setup.exe`) are signed. The portable zip and the `FetchJet.exe` inside the installers are not.
